Text used to check that real writing in each language can be typed with English letters
(`tests/test_typing_languages.py`).

- bengali, gujarati, kannada, malayalam, punjabi, tamil, telugu: Articles 1-5 of the
  Universal Declaration of Human Rights, from the UDHR in Unicode project
  (https://github.com/eric-muller/udhr). Zero-width joiners removed.
- odia, assamese: short everyday sentences written for these tests (no UDHR text is
  available in Unicode for them).
